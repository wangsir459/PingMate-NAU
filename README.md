# 南审乒搭 PingMate UI 原型

南京审计大学校园乒乓球搭子与等级约战平台的高保真可交互原型。

## 打开方式

直接打开 `index.html` 即可浏览；如果浏览器限制本地脚本，请在本目录启动任意静态文件服务器。

## 推荐演示路径

1. 首页查看 `cyw` 的 L2、直拍与 Elo 1000 信息。
2. 进入“搭子大厅”，查看林逸主页并发起排位约战。
3. 进入“我的约战”，打开与林逸的已确认比赛。
4. 提交 3:1 比分，展示 Elo 1000 → 1018、排名 #16 → #13。
5. 进入“排行榜”查看个人排名与校园榜单。

## 已实现页面与交互

- 首页与个人赛季概览
- 搭子大厅、筛选标签、选手卡片
- 选手详情抽屉
- 发起约战弹窗
- 我的约战状态看板
- 比分提交与结果确认
- Elo 更新反馈
- 校园排行榜
- 桌面端及移动端响应式布局

## 文件

- `index.html`：页面结构与演示数据
- `styles.css`：视觉系统、布局、动效及响应式规则
- `app.js`：页面切换、弹窗、抽屉与演示交互
